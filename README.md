BetterTwitch is a small add-on that makes Twitch chat easier to read and use. It adds useful chat tools without replacing Twitch or changing your account.

You do not need any programming knowledge to use it.

## What does it add?

- A panel for messages that mention you
- Live chat statistics and the top 10 chatters
- Buttons to reply, copy, pin, or translate messages
- Chat search, quick filters, and repeated-message cleanup
- Sounds and colors for mentions, moderators, and VIPs
- Options for chat width, avatars, badges, message separators, and colors
- Clearer information about links before you open them
- Optional automatic claiming of channel points and Drops
- English, German, and Russian interface languages

## Install

1. Install [ScriptCat](https://scriptcat.org/en), which lets your browser run BetterTwitch.
2. Open **[Install BetterTwitch](https://raw.githubusercontent.com/yaneony/BetterTwitch/main/BetterTwitch.user.js)**.
3. Confirm the installation, then open or reload a Twitch channel.

BetterTwitch buttons will appear at the bottom of the chat, close to Twitch's settings button. Updates are handled by ScriptCat.

## Privacy

- BetterTwitch has no advertising, analytics, or tracking.
- Your settings and chat statistics stay in your browser.
- Avatar requests are sent only to Twitch.
- Message text is sent to Google Translate only after you click the Translate button.

## Need help?

If a button is missing, reload Twitch first. Also check that ScriptCat is enabled for Twitch. Twitch changes often, so please include your browser and the affected Twitch page when reporting a problem.
